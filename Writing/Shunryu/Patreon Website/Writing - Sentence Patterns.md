【英文寫作】5大百搭句構技巧，輕鬆寫出華麗多變句式

無論是IELTS/ GMAT/ GRE/ TOFEL/ DSE的英文寫作部分，迅狐認為，靈活利用多元化英文句型，是最有用的特分技巧之一。尤其是IELTS Writing的Marking Scheme中，“Grammatical Range and Accuracy”一項正是考核考生能否運用複雜多變的句型。

因為，如果只用深奧的vocab，但句型卻只能用上最簡單的Subject-Verb-Object (S-V-O) structure，就像一套破舊西裝上面，襯上亮麗的領呔，考官會覺得很awkward。

迅狐建議，可以利用以下5種句構技巧，展示grammar功架。其實，可以準備一張checklist，每做一個tick一個，make sure自己盡用5種句構：


1. Passive voice (被動式)

e.g. 1. Such measures should be quickly adopted to… (= The government should quickly adopt such measures to …)


e.g. 2 Such problems could be tackled by … (=We can tackle such problems by…)



2. Relative clause

e.g. 1. The authorities should adopt these measures. These measures can help… → The authorities should adopt these measures which can help…

e.g. 2. The authorities should adopt these measures. Under these measures, citizens can… → The authorities should adopt these measures under which citizens can…


3. Conditionals (If — then)

    Type 0 (真理): If water reaches 100 °C, it boils.

    Type 1(正常): If it rains, we will stay at home.

    Type 2 (純想像，不可能發生): If I were you, I would not go./ If I had a pair of wings, I would fly to Tokyo.

    Type 3 (已發生，早知咁做啦): If I had eaten breakfast this morning, I would not have been so hungry.


4. Inversion (倒裝句)

e.g. 1. On no account/Under no circumstances can we…

e.g. 2. Not only should the authorities…, they should also…


5. Nominalisation (名詞化)

e.g. 1. The successful implementation of the plan brought immense profit to the company. (= The plan was implemented successfully and this brought immense profit to the company.) [動詞名詞化]

e.g. 2. It is of utmost/crucial/significant importance (It is very important…) [形容詞的名詞化]



另外，再為大家送上一堆實用百搭的英文寫作句式：

    6. In my opinion, /As far as I am concerned,/ From my point of view,/ I personally suppose…（於我而言）

    7. Undoubtedly, …/ There is no doubt that …/ No one can deny the fact that…/ We cannot ignore the fact that…/ It goes without saying that …（無可否認）

    8. It is public knowledge that… /It is generally acknowledged that…/ It is widely accepted that…(眾所周知)

    9. Similarly, / Likewise, / By the same token,/ In similar fashion, … (同樣地）

    10. In fact, /As a matter of fact, / Actually, (事實上)

    11. As a result,/ For this reason,/ Hence,/ Therefore,/ Consequently, (因此)

    12. For example, … / For instance, … / To illustrate, …/ … are prime examples of …/ A typical example of this would be…（舉例）

    13. In particular, / Particularly, / Specifically, (尤其)

    14. It is time the government took (past tense v.) proper steps to… (該是時候)

    15. Technology plays an key/important/crucial/vital role in our daily lives (扮演重要角色）

    16. This phenomenon causes/ brings/ leads to/ results in/ gives rise to …（引致)

    17. This will benefit/contribute to …/ This will bring forth positive/beneficial effects = This is advantageous (正面影響)

    18. This poses negative/adverse/detrimental/harmful impacts (負面影響)

    19. We should strive to v. / try out best to v./ do our utmost in v-ing… (竭盡所能)

    20. In conclusion,/ To summarise,/ To sum up, /All in all, (總而言之)
